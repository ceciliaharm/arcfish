# 🎣 ArcFish

**On-Chain Fishing Game on Arc Testnet**

Every action (Cast Line, Catch Fish, Claim Reward) requires a real transaction on Arc Testnet.

## How to Play
1. Get testnet USDC from https://faucet.circle.com (select Arc Testnet)
2. Connect your MetaMask wallet
3. Click **Cast Line** → confirm the transaction
4. Click the fish → each catch also requires a transaction
5. Claim your reward → another transaction
